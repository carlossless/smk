# SH68F89 Support

64KB of flash with a 4KB ISP bootloader at `0xF000`, 2816 bytes of xdata, a 256-byte USB
RAM window at `0x0B28`, and a separate 2KB EEPROM-like data block. Runs at 24MHz off the
PLL.

## MCU

- [x] Regulator (REGCON, brought up with the PLL)
- [x] CPU Clock (PLL, 24MHz SYSCLK)
- [x] GPIO
- [x] UART (EUART0; EUART1 is there but unmapped)
- [x] PCA (four units, 9 compare channels, the part's only PWM)
- [x] USB
- [x] SPI
- [x] TWI
- [x] Flash and EEPROM read/write (SSP)
- [x] ISP (jump)
- [x] Settings store (boards here keep them off-chip; the on-chip EEPROM block would work,
      through the same `flash` nvm module the other parts use)
- [ ] Sleep (Power-Down)

## Stores

`flash.c` is the SSP engine, and it is the same on every part: IB_CON2..5 take a fixed key to
arm one byte-program or one sector-erase, and `FLASHCON.FAC` swaps the data window into the
MOVC address space. What differs is what there is to address, which is the part's `nvm_hw.h`:

| store | where | survives a reflash |
| --- | --- | --- |
| EEPROM-like block | 2 KB of 256-byte sectors from `0x0000` in the FAC window | yes |
| information block | `0x1000` and up in the same window | yes |

## On-chip buses

The pins below are the part's, not a board's choice: the block takes them over when it is
enabled, so a board whose matrix or backlight already owns one cannot use that block.

| block | pins | driver |
| --- | --- | --- |
| EUART0 | TXD P6.4, RXD P6.5 | `uart.c`, `-Ddebug_sink=uart` |
| EUART1 | TXD1 P4.6, RXD1 P4.7 | unmapped |
| SPI | SCK P0.0, SS P0.1, MOSI P0.2, MISO P0.3 | `spi.c` |
| TWI | SCL P6.6, SDA P6.7 | `twi.c` |

SPR divides fSYS by 2 through 256, one step faster at each code than the other two
parts. The EUART sits at `0x98`-`0x9e`, which is PCA0 on page 1, and the TWI block is on
page 1 outright, so both drivers pin the page around every access. The ciy-x77 drives
matrix columns 0-3 on P0.0-P0.3, so SPI is not available there; its EUART and TWI pins
are free.

## Paged SFRs

Like the SH68F881 this part multiplexes two register banks onto the same SFR addresses,
selected by `INSCON.BKS0`. Use `sfr_page_0()` / `sfr_page_1()`, and save and restore
`INSCON` around any code that runs from an interrupt.

Roughly: page 0 holds ports P0-P4, both EUARTs, Timer2/3, the LCD registers, the DAC, SPI,
the clock and the flash `IB_*` registers; page 1 holds ports P5-P7, the four PCA units,
USB, TWI and the ADC.

Three differences from the SH68F881 bite in practice:

- `EP0CON`, `EP1CON` and `EP2CON` are at `0xBF`, `0xAA` and `0xAB`, none of which is
  bit addressable. Every endpoint bit is a mask for a read-modify-write.
- Interrupt numbers 0-3 are the four PCA units, not INT0/Timer4/INT1/Timer3. Timer3 is 11
  and USB is 12.
- USB RAM starts at `0x0B28`, above 40 bytes of LCD RAM, not at `0x0A00`.

## Datasheet

SinoWealth publishes no datasheet for this part, but it is register-for-register the
**SH88F6162**, which has a full 205-page English one. Read that as the SH68F89 datasheet
and take the SH88F6162 column wherever the two parts are distinguished; the only
difference is that the SH88F6161 has no USB.

The register map here is transcribed from `SH88F6161/SH88F6162 V2.2` section 7 and
cross-checks clean against the vendor Keil header `SH68F89.h` at all 358 declarations.
