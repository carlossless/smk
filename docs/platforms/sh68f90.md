# SH68F90 / SH68F90A (BYK901 / BYK916) Support

## MCU

- [x] 3.3V LDO
- [x] CPU Clock (use 24Mhz as SYSCLK)
- [x] GPIO
- [x] UART
    - [x] Transmit
    - [x] Receive
- [x] PWM
- [x] USB
- [x] SPI
- [x] ISP (jump)
- [x] Sleep (Power-Down)

## On-chip buses

The pins below are the part's, not a board's choice: the block takes them over when it is
enabled, so a board whose matrix or backlight already owns one cannot use that block.

| block | pins | driver |
| --- | --- | --- |
| EUART | TXD P5.5, RXD P5.6, or P3.3/P3.4 with `MAPPING` = `0xa5` | `uart.c`, `-Ddebug_sink=uart` |
| SPI | SCK P7.4, SS P7.3, MOSI P7.2, MISO P7.1, or P3.3/P3.4/P3.5 with `MAPPING` = `0xa5` | `spi.c` |
| TWI | none on this part | `bb_i2c.c` on any two pins |

SPR divides fSYS by 4 through 512. The nuphy-air60 has `CONN_MODE_SWITCH` on P5.5 and
its matrix rows on P7.1-P7.3, so neither block is available there; the eyooso-z11 leaves
both sets free.
